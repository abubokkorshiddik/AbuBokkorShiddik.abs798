Descriptive Statistics
Measures of Central Tendency
📖
What it is

The "Centre" of Data

A single value representing the typical value. The three primary measures are Mean, Median, Mode, each optimal under different data conditions.

🔢
Key Formulas

The Big Five

  • AM: Σx / n
  • GM: (x₁·x₂·…·xₙ)^(1/n)
  • HM: n / Σ(1/xᵢ)
  • Median: Middle sorted value
  • Mode: Most frequent value
✅
When to Use Each

Right Tool, Right Job

  • Mean: Symmetric data, no outliers
  • Median: Skewed data, income, housing
  • Mode: Categorical data
  • GM: Growth rates, index numbers
  • HM: Rates and speeds
⚠️
Cautions

Common Mistakes

  • Mean is sensitive to outliers
  • Never use mean for nominal data
  • AM ≥ GM ≥ HM always holds
  • Mode may not exist or be unique
Arithmetic Meanx̄ = (1/n)·Σᵢ xᵢ
Geometric MeanGM = (x₁·x₂·…·xₙ)^(1/n) = exp[(1/n)Σ ln xᵢ]
Harmonic MeanHM = n / Σᵢ(1/xᵢ)
InequalityHM ≤ GM ≤ AM (equality iff all xᵢ equal)
Key Quote"Statistics is the grammar of science." — Karl Pearson. Right measure of centre matters more than most students realise.

Spread of Data
Measures of Dispersion
📏
What it is

Quantifying Variability

Dispersion measures the spread or variability in a dataset. Two datasets can share the same mean but have vastly different spreads.

⚙️
All Measures

Absolute & Relative

  • Range: Max − Min
  • QD: (Q3−Q1)/2
  • MD: Σ|x−x̄| / n
  • Variance σ²: Σ(x−x̄)² / n
  • SD σ: √Variance
  • CV: (σ/x̄)×100 — unit-free
Sample Variances² = (1/(n−1))·Σᵢ(xᵢ − x̄)²
Computing formulaσ² = (1/n)Σxᵢ² − x̄²
Coeff. of VariationCV = (σ / x̄) × 100%

Correlation
🔗
What it is

Measuring Association

Correlation measures the strength and direction of the linear relationship between two variables. Pearson's r ranges from −1 to +1.

⚠️
Critical Warning

Correlation ≠ Causation

High correlation does not prove one variable causes the other. A lurking variable may drive both. Always investigate mechanism.

Pearson's rr = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²]
Spearman's ρρ = 1 − 6Σdᵢ² / [n(n²−1)]
r² (Coeff. of Det.)r² = Explained variation / Total variation

Complement of Unions

  • (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ

Discrete Distributions
Binomial & Poisson
🎰
Binomial(n, p)

n Independent Bernoulli Trials

  • P(X=k) = C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ
  • E(X) = np; Var(X) = np(1−p)
  • Fixed n, constant p, independent trials
☎️
Poisson(λ)

Rare Events in Time/Space

  • P(X=k) = e⁻λ·λᵏ / k!
  • E(X) = Var(X) = λ (unique!)
  • Calls/hour, defects/unit, accidents/year
🔢
Geometric(p)

Waiting for First Success

  • P(X=k) = (1−p)^(k−1)·p
  • E(X) = 1/p; Var(X) = (1−p)/p²
  • Memoryless property
Binomial PMFP(X=k) = C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ
Poisson PMFP(X=k) = e⁻λ·λᵏ / k!
HypergeometricP(X=k) = C(K,k)·C(N−K,n−k) / C(N,n)

Normal N(μ, σ²)

The Bell Curve

  • 68-95-99.7 rule for 1σ, 2σ, 3σ
  • Z = (X−μ)/σ ~ N(0,1)
  • Foundation of CLT & all classical tests
⏱️
Exponential(λ)

Time Until First Event

  • f(x) = λe⁻λˣ for x ≥ 0
  • E(X) = 1/λ; Memoryless!
Normal PDFf(x) = (1/σ√2π)·exp[−(x−μ)²/(2σ²)]
Exponential PDFf(x) = λ·e⁻λˣ, x ≥ 0; E(X) = 1/λ
Gamma PDFf(x) = xᵅ⁻¹·e⁻ˣ/ᵝ / [βᵅ·Γ(α)], x>0
Beta PDFf(x) = xᵅ⁻¹(1−x)ᵝ⁻¹/B(α,β), x∈[0,1]
Quick Selection GuideBinary trial → Bernoulli. Counting n-trial successes → Binomial. Rare events → Poisson. Waiting time → Geometric/Exponential. Without replacement → Hypergeometric. Heights/averages → Normal. Proportions → Beta.

S3
The Crown Jewel
Central Limit Theorem (CLT)
👑
The CLT

Most Important Theorem

Let X₁,…,Xₙ be iid with mean μ and finite variance σ². Then as n→∞: √n(x̄−μ)/σ →_d N(0,1) regardless of population shape. For n≥30: x̄ ≈ N(μ, σ²/n).

⚠️
When CLT Fails

Important Exceptions

  • Cauchy distribution (no finite variance)
  • Very small n with highly skewed data
  • Dependent observations
CLT (formal)√n(x̄ − μ)/σ →_d N(0,1) as n→∞
SE of x̄SE(x̄) = σ/√n
t statisticT = (x̄ − μ)/(s/√n) ~ t(n−1)
χ² from variance(n−1)s²/σ² ~ χ²(n−1)
CI for μ (σ unknown)x̄ ± t_{α/2, n−1}·s/√n
Sample size for μn = (z_{α/2}·σ / E)²

Core Test
One-Way ANOVA
⚙️
The Logic

Between vs Within Variance

  • MSA (between): Measures group-mean differences
  • MSE (within): Measures random error
  • Under H₀: F = MSA/MSE ≈ 1
  • Under H₁: F >> 1 → reject H₀
💡
Designs

CRD · RBD · LSD

  • CRD: Fully random; df_error = N−t
  • RBD: Block nuisance; df_error = (t−1)(b−1)
  • LSD: Two-way blocking; t×t square
F statisticF = MSA/MSE ~ F(g−1, N−g) under H₀
η² effect sizeη² = SSA/SST (small=.01, medium=.06, large=.14)
Two-way modelYᵢⱼₖ = μ + αᵢ + βⱼ + (αβ)ᵢⱼ + εᵢⱼₖ
Tukey HSD|ȳᵢ − ȳⱼ| > q_{α,g,N−g}·√(MSE/n) → significant

Errors, Power & Decision Rules
⚖️
Error Types

Four Outcomes

  • ✅ H₀ true, Don't reject: Correct (1−α)
  • ❌ H₀ true, Reject: Type I error α
  • ❌ H₀ false, Don't reject: Type II error β
  • ✅ H₀ false, Reject: Power = 1−β
🏆
N-P Lemma

Most Powerful Test

Reject H₀ when Λ(x) = L(θ₁)/L(θ₀) > k. Derives the optimal rejection region from the likelihood ratio.

Type I error αP(reject H₀ | H₀ true)
Power1 − β = P(reject H₀ | H₁ true)
LRT statisticΛ = L(θ̂₀)/L(θ̂); −2 ln Λ →_d χ²(r) under H₀
Kruskal-Wallis HH = [12/N(N+1)]Σ Rᵢ²/nᵢ − 3(N+1) ~ χ²(g−1)
p-hacking Warning"If you torture your data long enough, it will confess to anything." — Ronald Coase. Pre-register hypotheses before seeing data. Always report effect sizes alongside p-values.

📐
Properties

Key Properties of MVN

  • Marginals are normal
  • Conditionals are normal
  • Linear combinations are normal
  • Uncorrelated → Independent (unique to MVN!)
  • Quadratic form ~ χ²(p)

Contours

Elliptical Contours

Contours of constant density are ellipsoids in p-space. Shape determined by Σ. Axes = eigenvectors of Σ; lengths ∝ √λᵢ.

MVN pdff(x) = (2π)^(−p/2)|Σ|^(−1/2) exp[−½(x−μ)'Σ⁻¹(x−μ)]
Mahalanobis Distanced²(x,μ) = (x−μ)'Σ⁻¹(x−μ) ~ χ²(p)
Hotelling T²T² = n(x̄−μ₀)'S⁻¹(x̄−μ₀); F = [(n−p)/p(n−1)]·T²
Wilks' LambdaΛ = |E| / |H+E| ∈ (0,1]; Λ≈1 → fail to reject
Wishart(n−1)S ~ Wₚ(n−1, Σ) — matrix analogue of χ²

G2
Core Method
Genome-Wide Association Studies (GWAS)
🧬
What it is

Scanning the Entire Genome

GWAS tests millions of SNPs (single nucleotide polymorphisms) simultaneously for association with a phenotype (disease, trait). Typically tests ~1–10 million SNPs using logistic regression (binary) or linear regression (quantitative trait).

⚠️
Multiple Testing

The Genome-Wide Significance Threshold

  • Standard threshold: p < 5×10⁻⁸ (Bonferroni for ~1M independent tests)
  • False Discovery Rate (FDR) via Benjamini-Hochberg for exploratory analyses
  • Genomic inflation factor λ_GC — detects population stratification
💡
Confounding

Population Stratification

Different ancestry subgroups have different allele frequencies AND different disease rates. This creates spurious associations. Corrected by including first 10–20 principal components of the genetic relatedness matrix as covariates.

⚙️
Downstream Analyses

After GWAS

  • LD-score regression: Estimates heritability and genetic correlation
  • Mendelian Randomisation: Uses SNPs as instruments for causal inference
  • Polygenic Risk Scores: Aggregate SNP effects for individual prediction
GWAS model (binary)logit[P(Y=1)] = β₀ + β₁·SNP + β₂X₁ + … + βₖPCₖ
Genome-wide thresholdα = 5×10⁻⁸ (Bonferroni for ~10⁶ independent SNPs)
BH FDRReject H₀₍ᵢ₎ if p₍ᵢ₎ ≤ (i/m)·q* (sort p-values; q*=FDR level)
Polygenic Risk ScorePRS = Σⱼ β̂ⱼ · SNPⱼ (sum over all genome-wide significant SNPs)
LD Score RegressionE[χ²ⱼ] = Nh²/M·ℓⱼ + 1 (heritability h² estimated from slope)

🔗
Linkage Disequilibrium

Non-random Allele Association

Two loci are in LD if their allele frequencies are correlated — not independent as expected under random mating. Measured by D', r². LD structure defines haplotype blocks and determines which SNPs tag others in GWAS imputation.

⚙️
Population Models

Hardy-Weinberg & Drift

  • Hardy-Weinberg Equilibrium: p²+2pq+q²=1 under random mating, no selection
  • Genetic drift: Random change in allele freq in small populations
  • FST: Fixation index — measures genetic differentiation between populations
LD measure DD = p_{AB} − p_A·p_B (deviation from expectation)
LD measure r²r² = D²/(p_A·p_B·p_a·p_b) ∈ [0,1]
Hardy-WeinbergP(AA)=p², P(Aa)=2pq, P(aa)=q² (p+q=1)
FSTFST = (H_T − H_S)/H_T (total vs subpopulation heterozygosity)

  • Test: DESeq2, edgeR, limma-voom

🔢
Multiple Testing

FWER vs FDR

  • FWER (Bonferroni): P(≥1 false positive) ≤ α — very conservative for genomics
  • FDR (Benjamini-Hochberg): Expected proportion of false positives among all rejections ≤ q* — preferred in genomics
  • q-value: FDR analogue of p-value
Negative Binomial modelY_gn ~ NB(μ_gn, α_g); log(μ_gn) = x_n'β_g + offset
BH procedureSort p₍₁₎≤…≤p₍ₘ₎; reject p₍ᵢ₎ ≤ (i/m)·q*
q-valueq(t) = FDR(t) = π₀·m·t / R(t) (R(t) = # rejected at t)

📡
Wide-Sense Stationarity

WSS Process

A stochastic process X(t) is WSS (weakly/wide-sense stationary) if: (1) E[X(t)] = μ (constant mean), (2) Cov[X(t), X(t+τ)] = R_X(τ) depends only on lag τ, not on t itself. Foundation for spectral analysis via Fourier transform.

🌊
Power Spectral Density

Frequency Domain Representation

PSD S_X(f) = ∫R_X(τ)e^(-j2πfτ)dτ (Wiener-Khinchin theorem). Describes how power is distributed across frequencies. Estimated by periodogram or Welch method. DFT converts sampled signal to frequency domain.

Autocorrelation functionR_X(τ) = E[X(t)·X*(t+τ)]
Wiener-KhinchinS_X(f) = ∫₋∞^∞ R_X(τ)·e^(-j2πfτ) dτ
DFTX[k] = Σₙ x[n]·e^(-j2πkn/N)
Periodogram estimateŜ(f) = (1/N)|X[k]|² (biased but consistent for large N)

Optimal Filtering
Kalman Filter & State-Space Models
🛰️
Kalman Filter

Optimal Recursive Estimator

The Kalman filter is the optimal linear estimator for linear Gaussian state-space models. It recursively updates estimates as new observations arrive — no need to store all past data. Used in GPS, robotics, finance, and aerospace navigation.

🔢
Particle Filter

Non-linear Non-Gaussian Extension

Sequential Monte Carlo (particle filter) approximates the posterior distribution using a weighted set of random "particles." Used when the Kalman filter's linearity/Gaussianity assumptions fail — e.g., robot localisation, object tracking.

State equationxₜ = Fxₜ₋₁ + wₜ, wₜ ~ N(0, Q)
Observation equationyₜ = Hxₜ + vₜ, vₜ ~ N(0, R)
Predict stepx̂ₜ|ₜ₋₁ = Fx̂ₜ₋₁; Pₜ|ₜ₋₁ = FPₜ₋₁F' + Q
Kalman gainKₜ = Pₜ|ₜ₋₁H'·(HPₜ|ₜ₋₁H' + R)⁻¹
Update stepx̂ₜ = x̂ₜ|ₜ₋₁ + Kₜ(yₜ − Hx̂ₜ|ₜ₋₁); Pₜ = (I−KₜH)Pₜ|ₜ₋₁
Kalman InsightThe Kalman gain Kₜ is a weighted average between the prediction and the observation. When R is small (accurate sensor), Kₜ → H⁻¹ (trust observation). When Q is small (accurate model), Kₜ → 0 (trust prediction). The filter automatically balances model vs observation uncertainty.

D2
Fertility Measurement
Fertility Rates — CBR, TFR, GRR, NRR
👶
Key Fertility Measures

From Crude to Net

  • CBR: Crude Birth Rate = births per 1000 population — crude, affected by age structure
  • ASFR: Age-Specific Fertility Rate = births to women 15–49 in each 5-year age group
  • TFR: Total Fertility Rate = synthetic cohort lifetime births per woman = Σ ASFR×5
  • GRR: Gross Reproduction Rate — TFR × fraction female births
  • NRR: Net Reproduction Rate — accounts for female mortality → NRR=1 means replacement level
💡
Replacement Level

NRR = 1 → Long-run Stability

NRR > 1: population eventually grows. NRR < 1: eventual decline. NRR = 1: exact replacement. Bangladesh NRR dropped below 1 around 2010 — long-run population stabilisation expected. TFR ≈ 2.1 is replacement level in low-mortality populations.

CBRCBR = (Births / Mid-year population) × 1000
TFRTFR = 5·Σ_{a=15,20,…,45} ASFR_a (sum over 7 age groups × 5yr interval)
GRRGRR = TFR × f_F (f_F = fraction of births that are female ≈ 0.4878)
NRRNRR = 5·Σ_a ASFR_a · f_F · _5L_a / l_0 (_5L_a from life table)

Life Table

Cohort Mortality Experience

A life table traces a hypothetical cohort of l₀ births through age-specific mortality rates. Key columns: nₓ (age), nqₓ (prob. of dying in [x,x+n)), lₓ (survivors at exact age x), ndₓ (deaths), nLₓ (person-years lived), Tₓ (total future person-years), eₓ (life expectancy at age x).

Kaplan-Meier & Cox

  • Log-rank test: Compare survival curves between groups

Projection Methods
Cohort-Component Population Projection
📈
What it is

Forward Projection Method

Cohort-component projects a base population forward using assumed age-sex-specific fertility, mortality, and migration rates. The population is projected in 5-year age groups and 5-year periods using Leslie matrix algebra. Used by UN, World Bank, and national statistical offices for all official population projections.

⚙️
Leslie Matrix

Matrix Projection

P(t+1) = L·P(t) where L is the Leslie matrix with fertility rates in the first row and survival ratios on the sub-diagonal. The dominant eigenvalue λ₁ gives the long-run growth rate r = ln(λ₁). The corresponding eigenvector gives the stable age distribution.

Balancing equationP(t+n) = P(t) + Births − Deaths + In-migrants − Out-migrants
Leslie matrix LL[1,a] = Fₐ (fertility); L[a+1,a] = Sₐ (survival); all else = 0
Long-run growthr = ln(λ₁) where λ₁ = dominant eigenvalue of L
Stable age dist.c(a) = b·e^(-ra)·l(a) (b=birth rate, l(a)=survivorship to age a)
Bangladesh ProjectionBangladesh's population was 75 million in 1971; projected to peak around 185–200 million near 2050 before stabilising. The rapid TFR decline from 6.0 (1971) to 2.0 (2021) is one of history's fastest demographic transitions — driven by female education, contraception access, and women's labour force participation.

The Bayesian Paradigm Bayesian statistics treats unknown parameters as random variables with probability distributions — not fixed unknowns. This allows incorporating prior knowledge, naturally propagating uncertainty, and producing full posterior distributions rather than point estimates. The key equation: Posterior ∝ Likelihood × Prior. In the age of modern computation (MCMC, Stan, PyMC), Bayesian methods are now practical for complex, hierarchical real-world problems.

B1
Core Framework
Bayesian Inference — Posterior, Likelihood, Prior
🔄
Bayes' Theorem

Updating Beliefs with Data

p(θ|y) ∝ p(y|θ)·p(θ). The posterior p(θ|y) summarises all uncertainty about θ after observing data y. It combines the likelihood p(y|θ) — how well the data fit the model — with prior knowledge p(θ).

📊
Conjugate Priors

Closed-Form Posteriors

  • Beta-Binomial: Beta(α,β) prior × Binomial → Beta posterior
  • Normal-Normal: N(μ₀,τ₀²) prior × N(θ,σ²) data → Normal posterior
  • Gamma-Poisson: Gamma(α,β) prior × Poisson → Gamma posterior
💡
Prior Choices

Weakly Informative & Jeffreys

  • Jeffreys: p(θ) ∝ √|I(θ)|; invariant under reparametrisation
  • Weakly informative: Regularise without dominating (recommended by Gelman)
  • Flat/improper: p(θ) ∝ 1; can give improper posteriors!
Bayes' Theoremp(θ|y) = p(y|θ)·p(θ) / p(y) ∝ p(y|θ)·p(θ)
Beta-BinomialPrior Beta(α,β) + data (k successes, n trials) → Beta(α+k, β+n−k)
Posterior meanE[θ|y] = (α+k)/(α+β+n) (weighted avg of prior mean and MLE)
95% Credible Interval[θ_{0.025}, θ_{0.975}] such that P(θ_{.025} ≤ θ ≤ θ_{.975}|y) = 0.95

MCMC — Metropolis-Hastings & Gibbs Sampler
⛓️
MCMC Principle

Sampling the Posterior

When the posterior has no closed form, MCMC constructs a Markov chain whose stationary distribution IS the posterior. After a burn-in period, samples approximate draws from p(θ|y). Key diagnostics: R-hat (chain convergence), effective sample size (ESS), trace plots.

💡
Hierarchical Models

Partial Pooling

Hierarchical models have parameters at multiple levels: within-group (θⱼ), between-group (hyperparameters μ,τ). MCMC samples all levels jointly. Provides "partial pooling" — between no pooling (fixed effects) and complete pooling (single mean). Controls for multiple comparisons naturally.

MH acceptance ratioα = min[1, p(θ*|y)·q(θᵢ|θ*) / p(θᵢ|y)·q(θ*|θᵢ)]
Gibbs updateSample θⱼ from p(θⱼ | y, θ₋ⱼ) (full conditional)
R-hatR̂ = √[(W + B/n)/W] (W=within-chain var; B=between-chain var; → 1)
WAICWAIC = −2(lppd − p_WAIC) (lppd=log predictive density; lower = better)

Core Principle
Bias-Variance Tradeoff & Regularisation
⚖️
Bias-Variance

The Fundamental Tradeoff

  • Bias: Error from wrong assumptions — underfitting; high bias model can't capture truth
  • Variance: Error from sensitivity to training data — overfitting; high variance model fits noise
  • Tradeoff: Reducing bias often increases variance; optimal complexity minimises total error
🎯
Regularisation

Penalising Complexity

  • Ridge (L2): Add λ‖β‖² to OLS loss; shrinks all coefficients toward zero; handles multicollinearity
  • Lasso (L1): Add λ‖β‖₁; sparse solution — some β exactly zero; automatic variable selection
  • Elastic Net: Combines L1+L2; best of both
💡
Cross-Validation

Selecting λ

k-Fold CV: split data into k folds; train on k−1, test on 1; repeat k times; average test error. Minimise CV-error over λ grid. k=5 or k=10 is standard. LOOCV is equivalent to generalised CV (GCV) for linear models.

MSE decompositionE[(ŷ−y)²] = Bias(ŷ)² + Var(ŷ) + σ²
Ridge objectivemin_β Σ(yᵢ − β'xᵢ)² + λ‖β‖²₂ → β̂_ridge = (X'X + λI)⁻¹X'y
Lasso objectivemin_β Σ(yᵢ − β'xᵢ)² + λ‖β‖₁ (no closed form; coordinate descent)
k-Fold CV errorCV(λ) = (1/n)Σₖ Σᵢ∈Cₖ (yᵢ − ŷᵢ^(-k))²

Dependence Measures
Spatial Autocorrelation — Moran's I
🗺️
Moran's I

Global Spatial Autocorrelation

Moran's I tests whether spatial clustering is stronger than expected under complete spatial randomness. I ≈ +1: perfect clustering (similar values together). I ≈ −1: perfect dispersion (neighbours dissimilar). I ≈ 0: random spatial pattern. Requires a spatial weights matrix W.

💡
Kriging

BLUP Spatial Interpolation

Kriging predicts values at unobserved locations as a weighted average of nearby observations — weights chosen to minimise prediction error (BLUE for spatial processes). Requires a fitted variogram model. More powerful than inverse-distance weighting because it uses the full spatial covariance structure.

Moran's II = [n/(Σᵢ Σⱼ wᵢⱼ)] · [Σᵢ Σⱼ wᵢⱼ(xᵢ−x̄)(xⱼ−x̄)] / [Σᵢ(xᵢ−x̄)²]
Empirical variogramγ̂(h) = (1/2|N(h)|)·Σ_{N(h)} [z(sᵢ)−z(sⱼ)]²
Kriging predictorẑ(s₀) = Σᵢ λᵢ·z(sᵢ) (λ from solving kriging system)
SAR modely = ρWy + Xβ + ε (ρ = spatial lag parameter)
CAR modelY|Y_{-i} ~ N(μᵢ + Σⱼ bᵢⱼ(Yⱼ−μⱼ), σᵢ²)
