CONFIGURATION

Data settings

Connect the dashboard to JSON files published alongside your GitHub Pages website.

Dataset connection

Provide a path to a public JSON file.

Recommended format: a JSON array of papers, or an object containing an articles array.
Optional manifest: an array of reports with title, date, summary, and url fields.

How to connect your backend

Keep API credentials on the server side.

1
Publish the data

Have your Python workflow write articles to data/articles.json or copy it into the Pages folder.

2
Publish report metadata

Create data/reports.json listing report titles, dates, summaries, and public report URLs.

3
Keep the secret safe

Use GitHub Actions Secrets for OPENAI_API_KEY. Never place it in HTML or browser JavaScript.

4
Check relative paths

If this file is in a subfolder, adjust JSON paths to match the published website structure.
