How automated updates work

  1. A GitHub Actions workflow runs the Python collector.
  2. The collector retrieves scholarly metadata from its configured literature sources.
  3. The workflow writes updated articles.json and reports.json files.
  4. This dashboard fetches those public JSON files when you refresh it.
GitHub Pages only serves the HTML, CSS, JavaScript, and JSON files. It does not execute Python. Never put your OpenAI API key in this HTML or any public JSON file.
