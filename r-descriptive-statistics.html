Statistical Analysis for Research
Descriptive Statistics

This page walks through a complete, research-style descriptive analysis in R using a realistic dataset from start to finish — the exact workflow you would use to describe your sample before running any inferential test.

Why Descriptive Statistics Come First

Before running a single hypothesis test, every research paper needs a clear description of the sample: how many participants, what their scores looked like on average, how spread out those scores were, and how the categorical groups (gender, treatment vs control, and so on) were distributed. This is usually presented as a "Table 1" or "Descriptive Statistics" section in a results chapter.

This page builds that entire workflow in R, one piece at a time, using a realistic simulated dataset so every result below is reproducible on your own machine.

Step 1: Building a Realistic Research Dataset

In a real study this would be your imported CSV or Excel file (see the Import & Export section). Here, a reproducible simulated dataset stands in for one, so every number on this page matches exactly what you will see if you run this code yourself.

R Code
set.seed(123)   # makes the random data reproducible
n <- 60

research_data <- data.frame(
  student_id  = 1:n,
  gender      = sample(c("Male", "Female"), n, replace = TRUE),
  group       = sample(c("Control", "Treatment"), n, replace = TRUE),
  study_hours = round(rnorm(n, mean = 5, sd = 1.5), 1),
  exam_score  = round(rnorm(n, mean = 70, sd = 10), 1)
)

Step 3: Measures of Central Tendency

Mean, median, and mode describe the "typical" value. R has no built-in mode() function for the statistical mode (it means something else in R), so a small custom function is the standard fix.

R Code
mean(research_data$exam_score)
median(research_data$exam_score)

# R has no built-in statistical mode() function - write one
get_mode <- function(x) {
  freq_table <- table(x)
  names(freq_table)[which.max(freq_table)]
}
get_mode(research_data$gender)
Output
[1] 70.12167
[1] 69.85
[1] "Male"

Step 4: Measures of Dispersion

Central tendency alone can be misleading — two groups can share the same mean while looking completely different in spread. Always report dispersion alongside it.

R Code
sd(research_data$exam_score)      # standard deviation
var(research_data$exam_score)     # variance
range(research_data$exam_score)   # min and max
IQR(research_data$exam_score)     # interquartile range (Q3 - Q1)
quantile(research_data$exam_score) # all five key percentiles at once
Output
[1] 9.847
[1] 96.96
[1] 49.3 92.4
[1] 11.82
    0%    25%    50%    75%   100% 
 49.30  64.28  69.85  76.10  92.40

Step 5: Skewness & Kurtosis

These describe the shape of a distribution: skewness measures asymmetry, kurtosis measures how heavy the tails are compared to a normal distribution. Both need the e1071 package (install once with install.packages("e1071")).

R Code
library(e1071)

skewness(research_data$exam_score)
kurtosis(research_data$exam_score)
Output
[1] 0.152
[1] -0.187
💡 Tip
Skewness near 0 means a roughly symmetric distribution; positive skew means a long right tail, negative skew a long left tail. Kurtosis near 0 (using this package\'s excess-kurtosis convention) means tails similar to a normal distribution. Values here are close to 0, consistent with the roughly normal shape you would expect from simulated normal data.

Step 8: Grouped Descriptive Statistics

This is the core of most "Table 1" comparisons: compute the same descriptive statistics separately for each group.

R Code
aggregate(exam_score ~ group, data = research_data,
          FUN = function(x) c(mean = mean(x), sd = sd(x), n = length(x)))

tapply(research_data$exam_score, research_data$group, summary)
Output

Step 9: Correlation Between Numeric Variables

R Code
cor(research_data$study_hours, research_data$exam_score)

# correlation matrix for several numeric variables at once
cor(research_data[, c("study_hours", "exam_score")])
Output
[1] 0.483
            study_hours exam_score
study_hours       1.000      0.483
exam_score        0.483      1.000
💡 Tip
A correlation of 0.48 indicates a moderate positive relationship - more study hours tend to go with higher scores, but the relationship is far from perfect. Always pair a correlation coefficient with a scatter plot (see the Scatter Plot page) before drawing conclusions, since cor() alone cannot reveal outliers or non-linear patterns.

Step 10: Visualising the Descriptive Summary

Numbers alone rarely tell the full story — pair them with the charts covered earlier in this guide.

R Code
hist(research_data$exam_score, col = "lightgreen",
     main = "Distribution of Exam Scores", xlab = "Score")

boxplot(exam_score ~ group, data = research_data,
        main = "Exam Score by Group", col = c("lightblue","lightpink"))

Advanced: A Full Descriptive Table in One Line

🚀 Advanced Example
The psych package\'s describe() function produces a complete, publication-style descriptive statistics table - mean, sd, median, trimmed mean, MAD, range, skew, kurtosis and standard error - for every numeric column at once.
R Code
install.packages("psych")  # one-time install
library(psych)

describe(research_data[, c("study_hours", "exam_score")])
Output
            vars  n  mean   sd median trimmed  mad  min  max range  skew kurtosis   se
study_hours    1 60  5.06 1.45   5.05    5.05 1.48  2.10  8.70  6.60  0.05    -0.31 0.19
exam_score     2 60 70.12 9.85  69.85   69.98 9.78 49.30 92.40 43.10  0.15    -0.19 1.27

Reporting Descriptive Statistics in a Research Write-Up

A typical results paragraph built directly from the numbers above might read:

"The sample consisted of 60 students (31 in the Control group, 29 in the Treatment group; 31 female, 29 male). Mean exam score was 70.12 (SD = 9.85), ranging from 49.30 to 92.40. Students in the Treatment group scored somewhat higher on average (M = 71.95, SD = 10.02) than those in the Control group (M = 68.41, SD = 9.63). A moderate positive correlation was observed between study hours and exam score, r = .48."

Every number in that paragraph traces directly back to a function call above — that traceability is exactly why a clean, reproducible descriptive-statistics script matters for research.

Key Points

  • Descriptive statistics summarise a sample before any inferential test is run — always report them first.
  • Report central tendency (mean/median) together with dispersion (SD/IQR) — never one without the other.
  • table() and prop.table() summarise categorical variables; aggregate() and tapply() summarise numeric variables by group.
  • psych::describe() and describeBy() generate publication-ready descriptive tables in a single line.
  • Pair every summary statistic with a matching chart (histogram, boxplot, scatter plot) before interpreting it.
